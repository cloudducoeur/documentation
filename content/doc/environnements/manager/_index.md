Le **Manager** est la plateforme unifiée du Cloud du Coeur. Depuis une même interface web, il permet de gérer l'ensemble des produits du Cloud du Coeur.

{{% callout type="warning" %}}
Le Manager est actuellement en cours de développement. La bêta publique n'est pas encore accessible.
{{% /callout %}}
